# Halfsecond Studio

A browser app for making short-form ads that win the first half second. It has four tools that pass work to each other, plus a home screen that shows what is on the bench. There is no build step and no server. Open `index.html` in Chrome, Edge or Safari.

| Tool | What it does | Hands off to |
|---|---|---|
| **1 · Hook Lab** | A hook meter shows which words of your hook are read in the first 0.5 s (at about 4 words a second, so roughly two words) and scores the line on length, front-loading, specificity, tension, direct address and ad-speak. A four-line brief generates hooks from 28 formulas. A caption check previews the feed truncation and counts characters and hashtags. Inside claude.ai, **Write 10 with Claude** writes hooks from the brief. | The hook becomes the first card in Type Studio |
| **2 · Beat Grid** | Set BPM (or tap it), frame rate and target length. Shots are laid out in beats, and every cut gets exact seconds and frame numbers. It flags tempos where beats fall between frames and suggests nearby whole-frame tempos. Play runs a click track with a live cue sheet (now, next, timecode, bar and beat). Export as Markdown or CSV. It opens on the Reel 01 cut list. | The tempo drives Type Studio |
| **3 · Type Studio** | Each line becomes a kinetic type card that cuts on the beat. There are four treatments (serif slam, typewriter, stack, mask wipe), plus brand palettes, film grain, vignette and a timecode slate. A synthesised beat track is optional. **Export video** records a 1080×1920, 30 fps MP4 (or WebM where the browser can't write MP4). **Save frame** saves a PNG cover. | |
| **4 · Scroll-Stop Lab** | Load an image or a video; for a video it reads the first frame. Two versions are scored side by side on contrast, colour pop, one place to look, busyness and clearance from app UI. A **half-second test** swipes the creative through a phone feed for 0.25, 0.5 or 1 s. Four lenses (scroll-speed blur, squint with the estimated focal point, five-tone values, thumbnail) and a k-means palette help explain the score. Inside claude.ai, **Critique this frame** asks Claude for a verdict and three fixes. | The palette goes to Type Studio |

The scores are measured from the pixels and the words, using heuristics. They don't predict performance. Use them to compare versions of the same idea.

## Files

| Path | What it is |
|---|---|
| `index.html` | Markup and styles. The brand tokens (ink, cream, signal orange, Instrument Serif and Space Mono) are at the top of `<style>`. |
| `js/core.js` | Shared helpers: storage, toasts, clipboard, file saving, the Claude capabilities, the audio clock used by Beat Grid and Type Studio, and the safe-zone map. |
| `js/hooks.js` | Hook Lab: formulas, the scorer and the caption check |
| `js/beats.js` | Beat Grid |
| `js/type.js` | Type Studio: treatments, finish and export |
| `js/lab.js` | Scroll-Stop Lab: analysis, palette, lenses and the feed test |
| `js/main.js` | Home dial, bench and start-up |
| `js/samples.js` | The two sample frames, inlined so analysis also works from `file://`. Generated by `tools/make_samples.py` from `assets/`. |

## Notes

- Drafts (hook, brief, caption, cut list, Type Studio settings) are kept in your browser's local storage. Clearing site data resets them.
- Safe zones are approximate and deliberately cautious: the top 13 %, the bottom 22 % and a right-hand button column. Real overlays vary by app and device.
- Video export records in real time, so keep the tab in front while it runs. Chrome and Safari write H.264 MP4. Browsers without an MP4 encoder fall back to WebM, or to VP9 inside MP4.
- The Claude buttons only appear when the studio runs as a claude.ai artifact. Opened from disk, every other feature works without them.
