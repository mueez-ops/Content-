How a reel moves through the studio

  1. Hook Lab

    Generate hooks from a four-line brief and see which words land before the thumb moves.

    Hands the hook to Type Studio

  2. Beat Grid

    Tap the tempo of your track and lay shots out in beats. Every cut gets an exact frame number.

    Hands the tempo to Type Studio

  3. Type Studio

    Turn lines into kinetic type cards that cut on the beat, with grain, and export a 1080×1920 video.

    Uses palettes from the Lab

  4. Scroll-Stop Lab

    Score a first frame against a second version, view it at scroll speed, and check the app's UI isn't covering it.

    Hands a palette to Type Studio
